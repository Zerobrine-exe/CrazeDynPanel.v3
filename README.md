# 📦 **CrazeDynPanel v3 — Quick Installation Guide**

CrazeDynPanel v3 is a **lightweight** and **powerful** Minecraft server control panel for **Windows**.  
Enjoy a **simple setup**, **modern UI**, and **full web-based management**.

---

## 🚀 **Quick Install (Recommended)**

### **Method 1 — Using Git (Fastest)**
**If Git is already installed on your PC:**

```sh
git clone https://github.com/Zerobrine-exe/CrazeDynPanel.v3.git
cd CrazeDynPanel.v3
setup.bat
```

---

### **Method 2 — Download ZIP (No Git Required)**

1. Click **Code** → **Download ZIP**
2. Extract the ZIP **anywhere** (Desktop / Documents / any folder)
3. Open the folder
4. Double-click `setup.bat`

The panel will **install automatically!**

---

## 📁 **After Installation, You Get:**

- ✨ Full web-based panel  
- 🏗️ Server creation system  
- 👥 Player manager  
- 📦 Plugin marketplace (**Modrinth**)  
- 🌍 Worlds manager  
- 📜 Log viewer  
- 💻 Terminal console  
- 📦 Backup system  
- 🎨 Themes & video background support  
- ⚡ System optimization for Windows  
- 🔧 Everything preconfigured!

---

### **To Start Your Panel:**

Run:

```sh
Start_Desktop.bat
```

**OR open the web URL that setup shows.**

---

## 📌 **Requirements**

- Windows 10 / 11 (**64-bit**)
- Git (**optional**)
- **Java** installed (if running Minecraft servers)
- **Internet connection**
